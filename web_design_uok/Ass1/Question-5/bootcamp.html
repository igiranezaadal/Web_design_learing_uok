Internet Terms Glossary

URL
The web address used to locate a resource on the internet.
DNS
The directory system translating domain names to IP addresses.
IP address
A unique identifier numerical label assigned to every connected device.
HTTP
The foundational protocol powering data transfers over the web.
HTTPS
An encrypted secure version of the standard HTTP protocol.
